Supabase Cloud Database Settings

Connect your Fatima Parish Management System to your Supabase (PostgreSQL) cloud database for instant multi-device synchronization and automatic cloud storage.

From Supabase Dashboard → Settings → API → Project URL
From Supabase Dashboard → Settings → API → Project API Keys (anon public)
⚡ Quick Setup Guide:
  1. Create a free project at supabase.com.
  2. Go to SQL Editor, click Copy SQL Schema below, paste and run.
  3. Paste your Project URL & Anon Key above and click Test & Save Connection.
